# Keyboard Shortcuts

The menu commands' shortcuts, switching accounts, and the keys that work in sheets and documents.

These work on the Mac, and on iPad with a hardware keyboard. On iPad, hold ⌘ to see the menu commands.

## Make new items

| Shortcut | Command |
|---|---|
| ⌘N | New Login… |
| ⇧⌘N | New Encrypted Folder… |
| ⌥⌘N | New Document… |

On the Mac these are in the File menu, with **Sync a Folder…** and **Add Remote…**, which have no shortcut.

## Vault

| Shortcut | Command |
|---|---|
| ⌘R | Sync Now (iCloud, and the remotes your synced folders use) |
| ⌃⌘L | Lock All Folders, in every account (while a folder is decrypted) |
| ⌃⌘1 … ⌃⌘9 | Switch the window to your first nine accounts (with more than one account) |
| ⌘, | Settings (Mac) |

## In sheets and documents

| Shortcut | Does |
|---|---|
| Return | The sheet's main button: Save, Create, Connect, Add Document |
| Esc | Cancel the sheet |
| Esc | Back to the library from an open document (iPad and Mac) |
| ← → | The previous or next page, with a document's pages full screen |
| Esc | Close a document's full-screen pages |

## SSH agent (Mac)

| Shortcut | Does |
|---|---|
| Esc | **Deny** a signing request |
| Esc | **Ignore** a request that came while the agent was off |
| Return | **Add Line** when Vault asks to use the agent from Terminal |
| Esc | **Not Now** when Vault asks to use the agent from Terminal |
