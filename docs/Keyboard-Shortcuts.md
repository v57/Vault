# Keyboard Shortcuts

These work on the Mac, and on iPad with a hardware keyboard. On iPad, hold ⌘ to see them.

## Make new items

| Shortcut | Command |
|---|---|
| ⌘N | New Login… |
| ⇧⌘N | New Encrypted Folder… |
| ⌥⌘N | New Document… |

On the Mac these are in the File menu, with **Sync a Folder…** and **Add Remote…**.

## Vault

| Shortcut | Command |
|---|---|
| ⌘R | Sync Now (iCloud, and the remotes your synced folders use) |
| ⌃⌘L | Lock All Folders (while a folder is decrypted) |
| ⌃⌘1 … ⌃⌘9 | Switch the window to your first nine accounts |
| ⌘, | Settings (Mac) |

## In sheets and documents

| Shortcut | Does |
|---|---|
| Return | The sheet's main button: Save, Create, Connect, Add Document |
| Esc | Cancel the sheet |
| Esc | Back to the library from an open document |
